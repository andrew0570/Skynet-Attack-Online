## Rules
- Teams of 1–4; add all teammates to Devpost before submitting.
- All coding and building must be done during the hackathon.
- MLH Code of Conduct applies.
- Devpost submission needs a project description and **table number**.

## Judging
- 3-minute pitch + demo per judge visit; you may be judged multiple times.
- Q&A on technical aspects, creativity, impact, development process, challenges, future plans.
- Scoring criteria: **innovation, technical complexity, usability, presentation quality**.
- Sponsors judge their tracks concurrently.
