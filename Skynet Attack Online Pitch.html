The problem

Game bosses still follow a script.

AI in game development mostly helps people make games faster. Inside the game, enemies still run pre-ordered movesets: learn the pattern once, and the fight is solved forever.

Today

Fixed attack patterns, tuned once by designers, identical for every player.

What if

The boss reads how you play and picks counters on its own.

What if

Every fight, by every player, makes it smarter for everyone.

What if

It could explain why it chose each attack.

Project overview

One shared brain, trained by the whole community.

FIGHTYou battle Skynet in a 3D arena in the browser.
DECIDEEvery ~½ s it reads 29 signals about the fight and you, and picks 1 of 25 options.
VALIDATEAt the end, the server checks the whole fight log before trusting it.
LEARNThe shared brain updates; its version number ticks up.
EVOLVEThe next player, anywhere, fights the smarter Skynet.

Only players who opt in contribute · no personal data · fights that fail validation are never learned from

Reads your style

Tracks 8 habits: range, hiding, dashing, melee, skills, airtime, and more.

Counters it

Hunter Drones phase through walls for campers. Reflect Shield punishes beam spam. Feint baits dodgers.

Explains itself

"HUNTER DRONES — because you hide in cover." Hold Tab to see what it has learned.

Raid mode

Five fighters vs one Skynet, run live inside the database.
